## 問診票の質問

わかる範囲で答えてください。番号と答えだけの書き方で大丈夫です。★ は必須の項目です。

1. ★ いつから症状がありますか
   （今日 / 1〜2日前 / 3〜6日前 / 1週間以上前）
2. いまの体温（℃）
3. 当てはまる症状をすべて選んでください（ほかにあれば自由に書いてください）
   （せき / のどの痛み / 鼻水 / 頭痛 / 体のだるさ / 吐き気・おう吐 / 下痢 / 味やにおいがわからない）
4. 家族や周りに同じ症状の人はいますか（はい / いいえ）
5. ★ 持病はありますか（はい / いいえ）
6. 「はい」の場合、持病の名前
7. ★ いま飲んでいる薬はありますか（はい / いいえ）
8. 「はい」の場合、薬の名前（わからなければ、お薬手帳を持っていけば大丈夫です）
9. ★ 薬や食べ物のアレルギーはありますか（はい / いいえ）
10. 「はい」の場合、アレルギーの内容
11. 妊娠している、またはその可能性がありますか（はい / いいえ / あてはまらない）
12. そのほか、医師に伝えたいこと

答えをもらえたら、受付でそのまま見せられる形にまとめます。
